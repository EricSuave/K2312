KINGDOM 2312 — ADMIN MEMBER / PREP ENTRY

This ZIP includes the previous buff-only rankings and automatic scheduling changes.

INSTALL
1. Open 004_admin_member_prep.sql from the supabase/migrations folder (also provided as a separate download).
2. In your K2312 Supabase project, open SQL Editor > New query, paste the complete script, and click Run. Run this new script only; do not rerun migration 001.
3. Extract the ZIP and upload the app, components, data, lib, supabase and tests folders into their matching GitHub folders. Replace changed files and include new files.
4. Commit the update and wait for Vercel to show Ready.
5. Open Admin > KvK prep & schedule > Add member / enter prep for a player.

No environment-variable or API-key changes are needed. The SQL update is safe to rerun and preserves existing accounts and submissions.

USE
Enter the player's game member ID and KvK battle date. Click Load or add player. Enter their name and alliance, preparation amounts, minister requests, and preferred times. Save prep for this player.

New player records are created when prep is saved. No player registration, email, password, or fake account is created. Entering prep does not grant the player administrator access.

For an existing player, the latest prep for that battle date loads for editing. Admin-entered preparation is stored separately and marked Admin entered. The signed-in administrator is recorded as the editor. If both the member and an admin submit prep, the latest saved entry per player ID and battle date feeds the ranking and schedule once. Existing member-submitted forms remain intact.

If another admin or the player changes the record while you are editing, saving reports a conflict. Load the player again and review the latest details before saving.

Saving refreshes the ranking, chronological schedule, and admin list. Preferred time order is preserved. Only regular Truegold and the relevant speedup activities count. Existing Gen 2 / TG3 / T10 limits remain. The schedule remains an automatic draft that can change with new submissions; leadership confirms actual appointments in game.
